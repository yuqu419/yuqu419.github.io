栈

栈基础知识

栈是一种后进先出的数据结构。理解栈帧，有助于跟踪汇编中的函数调用、局部变量与返回过程。

栈的特点：

  • 向下增长，也就是从高地址到低地址

  • 栈的空间有限，一般只有几 MB，所以当声明过大数组或者深递归时可能会导致爆栈

  • 栈顶是低地址，栈底是高地址

  • rbp 寄存器内存储指向函数栈帧栈底的指针（地址），rsp 寄存器内存储指向栈顶的指针

  • 当在栈中读取数据时，是从低地址向高地址读取

    如 movq (%rsp), %rax，读取地址 0(%rsp) 至 7(%rsp) 的八个字节，写入 rax 寄存器

当调用函数时，一般会创建一个函数栈帧

pushq %rbp
movq %rsp, %rbp

增长栈：subq $Imme, %rsp

回收栈：addq $Imme, %rsp

当函数结束，函数栈帧会被回收

leave
ret

leave 所做的事情相当于

movq %rbp, %rsp
popq %rbp

栈安全

我们知道，每次产生一个函数栈帧时，会在这之前，压返回地址入栈，设想这种情况，假设在改动栈时，将返回地址修改了，那么当返回函数时，rip 内会被修改为一个无法确定甚至是被恶意修改的地址。这就是缓冲区溢出所带来的巨大风险，为了避免这种风险，在编写代码时尽量不使用不检查边界的函数，如 strcpy

栈保护机制

  • 栈随机化 每次运行程序时，栈的起始地址随机变化
  • Stack Canary（栈金丝雀） 栈金丝雀是编译器放在缓冲区和返回地址之间的一个随机值（具体位置有编译器确定），在返回函数前，检查栈金丝雀是否被修改，若被修改，则调用 __stack_chk_fail 函数，立即终止程序
  • 不可执行栈 栈被标记为不可执行的，避免攻击者将攻击代码放到栈上执行

函数调用

函数调用使用 call <func>

执行 call 时发生了以下几件事

  • 压栈 将 call 的接下来一条指令压入栈中，为函数执行完毕后继续运行做准备
  • 准备进入函数 将被调用函数的第一条指令的地址复制到 rip 中

寄存器 rip 是程序计数器，专门存储下一条指令的内存地址，在介绍寄存器时，详细介绍

另外，在使用 call 指令时，需要对齐，即保证 rsp 为 16 的整数倍

一般而言，函数需要创建自己的栈帧，但是叶子函数则不需要，叶子函数是不调用其他函数的函数

函数传参

前六个参数分别存储在六个寄存器中：rdi，rsi，rdx，rcx，r8，r9，当然，这六个寄存器只能存储整数和内存地址。更多参数存储在栈中，规则是按照从右往左的顺序压栈，这样就可以从左往右出栈

除此以外，还有一些其他规则。当传浮点数时，使用 8 个 SSE 寄存器（xmm0~xmm7），这种寄存器可存储 16 字节

所以说，并不是说函数传参超过 6 个就会压栈，而是要更根据参数参数的具体类型决定

可变参数

当使用可变参数时，还需设置 al 寄存器来表明用了多少个浮点数以优化速度

可变参数在返回地址的上方，callee 函数只负责读取，而 caller 函数需要负责清理

函数返回

函数的返回值大多数时候存储在 rax 寄存器中，但并非没有意外

  1. 寄存器类型限制 前面已经知道，rax 这类寄存器只能存储整数和内存地址，那么显然，如果返回浮点数，就需要 SSE 寄存器了，这是会将返回值存储到 xmm0 中

  2. 寄存器大小限制 这个需要分为两类，基础类型和复合类型：

    • 基础类型 当存储 128 位整数时没有寄存器能胜任这个任务，所以采取的方案时，拼装两个寄存器 rdx 和 rax，rdx 存储高 64 位，rax 存储低 64 位
    • 复合类型 当存储结构体时，采取的做法是将结构体拆分到 rax，rdx，xmm0，xmm1 中，若结构过大，则会采取，由 caller 分配内存，rax 存储其内存地址的方式

在函数的末尾，使用 ret 指令，其作用是将存放栈中的返回地址弹出，写入 rip 中

寄存器

寄存器是真实存在的物理实体，它是 CPU 的一种速度极快的存储器

通用寄存器

在 64 位系统中，前 8 个寄存器有自己的名字，它们分别是 rax，rbx，rcx，rdx，rsp，rbp，rdi，rsi，后 8 个寄存器就是 r8~r15，重点学习前 8 个寄存器

我们已经 rax，rcx，rdx，rsp，rbp，rdi，rsi 各有 ABI 为他们分配的任务，唯独 rbx 貌似没什么作用——事实上，它确实没有特殊作用。在习惯上，它常被用于数组的基址，但并非强制

调用者保存寄存器

调用者保存寄存器：即调用者负责保存的寄存器，所以被调用的函数可以随意对其进行修改，调用前后不保证寄存器内数据不变，有：rax,rdx,rcx,rsi,rdi,r8,r9,r10,r11,xmm0~xmm15 可以发现，调用者保存寄存器包括了参数存放和函数返回的寄存器，这些量是在函数调用前后才有意义的，而r10和r11是专门留作临时工的，特殊记忆即可

一个典型的误区是调用者保存不意味着调用者就会去保存，只是当需要保存时有调用者负责而已，其实大多数时候不会特意保存，故是易失的

被调用者保存寄存器

被调用者保存：即被调用者负责保存的寄存器，所以在函数调用前后可以保证其内数据不变，可以看作不易失的，包括rbx,rbp,r12,r13,r14,r15。从这里可以看出rbx的特殊之处

特殊寄存器

rsp：由调用者和被调用共同维护，并且作为栈的实际栈顶

虽然我们常常将 rbp 寄存器认为是当前函数栈底，但这不是严格的，只是约定俗称。而 rsp 确实严格为栈顶

rip：由 call/ret 隐式管理，无法显式地修改 rip

寄存器命名

在 64 位操作系统上，寄存器的命令法则有三套

  1. rax, rbx, rdx, rcx
大小 64 位 32 位 16 位 高 8 位 低 8 位
rax 类 rax eax ax ah al
rbx 类 rbx ebx bx bh bl
rcx 类 rcx ecx cx ch cl
rdx 类 rdx edx dx dh dl
  1. rdi, rsi, rsp, rbp
大小 64 位 32 位 16 位 低 8 位
rdi 类 rdi edi di dil
rsi 类 rsi esi si sil
rsp 类 rsp esp sp spl
rbp 类 rbp ebp bp bpl
  1. r8 ~ r15
大小 64 位 32 位 16 位 低 8 位
名称 r8~r15 r8d~r15d r8w~r15w r8b~r15b

关键规则：当写入32位寄存器时，会把高32位清零。但写入16位和8位并不会改变其他的数位

rflags 寄存器

rflags 寄存器是一个特殊的寄存器，它的每一位都都是特殊的标志位（高 32 位保留）

下面看常见的标志位：

  1. ZF（Zero Flag）：结果为 0 时为 1

  2. SF（Sign Flag）：最高位为 1 就为 1

  3. OF（Overflow Flag）：有符号溢出则为 1

  4. CF（Carry Flag）：无符号进位/借位则为 1

常用指令

指令是汇编中的核心操作，主要是通过操作栈和寄存器进行的。在编写时牢记以下几点：

  1. 在 AT&T 语法中，一律为 指令 源操作数, 目的操作数

  2. 每条指令最多访问一次内存，但可以多次访问寄存器

  3. 目的操作数不能是立即数

下面介绍以下常用指令：

数据传送指令

  • mov

    mov 是最常用的指令之一，它的作用是把源操作数中的数据复制到目的操作数

    如：movq %rax, %rbx

    表示把 rax 中存储的数据移动到 rbx 中，如果给 rax 加一层括号，就类似于 C 中的解引用操作

    movq (%rax), %rbx

    表示以 rax 中存储的数据为内存地址寻找数据，将找到的数据存储在 rbx 中

  • lea

    lea 非常容易与 mov 搞混，它代表直接读取源操作数的地址到目的操作数中

    leaq (%rax), %rbx

    表示将 rax 中存储的地址读取到 rbx 中

    值得注意的是，这里的 (%rax) 并非代表与上面类似的解引用操作，而是表明 rax 内存储着地址

    leaq %rax, %rbx是不合法的

    正是以为 leaq 的特性，常常被用作高效乘法，具体后面介绍

  • push 与 pop

    push 的原理等同于 sub + mov，即先存储空间，再将目的操作数的数据复制到栈中

    pop 的原理等于同 mov + add，即先将栈中内容复制到目的操作数中

算术与逻辑指令

  • 一元操作算术

    inc，dec，neg 三者分别对应自增，自减，取负

  • 二元操作算术

    add，sub 两者分别对应加，减

    lea 可以完成同等功能，但并非取代，在不同场景下有不同的最优解，一个比较明显的区别是 lea 并不会修改 rflags

  • 逻辑操作算术

    and，or，xor 分别表示与、或、异或

  • 移位操作算术

    sal, shl, sar, shr

    分别是算数左移（Shift Arithmetic Left），逻辑左移（Shift Logical Left），算数右移（Shift Arithmetic Right），逻辑右移（Shift Logical Right）

    其中逻辑表明直接执行位移操作而不进行额外判断

    算数表明执行位移操作时，会尽量使负数维持为负数，正数维持为正数。但左移必定破坏最高位符号位，所以逻辑左移等同算数左移

    另外对于源操作数有特殊要求，必须是立即数，或是存储在 cl 寄存器（rcx 的低 8 位）中

以上的指令都有显著特征：即会改变 rflags 寄存器，且在算数逻辑单元中执行运算

控制流指令

  • cmp 与 test

    cmp 的原理是，进行运算：目的操作数 - 源操作数，类似于 sub，但 cmp 不会保存运算结果，仅设置条件码

    test 与 cmp 类似，执行 and 操作，但不保留结果，仅设置条件码

  • jmp jmp 指令很简单 jmp Label 将 rip 内地址修改为 Label 地址

    jmp *%rax：表示跳转到 %rax 中存储的地址

    jmp *(%rax)：表示跳转到以 (%rax) 中存储的地址指向的数据为地址的内存地址

    难点在jmp 类指令，这类指令根据条件码的情况进行跳转操作，有以下几种

    1. je（jump if equal） ZF = 1 时跳转

    2. jne（jump if not equal） ZF = 0 时跳转

    3. jg（jump if greater） 用于有符号比较，需要综合考虑 SF，OF，ZF，类似的还有 jge，与 jg/jge 对应的是 jl/jle（jump if less/jump if less or equal）

    4. ja（jump if above） 用于无符号比较，需要综合考虑 CF，ZF，类似的还有 jae，与 ja/jae 对应的是 jb/jbe（jump if less/jump if less or equal）

    记忆这几个的方法是记住，所有的大或者小都是相对于目的操作数而言的

流程控制的主要目的是模拟 C 中的 for，while，do-while

函数调用与栈帧指令

call，ret，leave 这三个指令在上面已经介绍得很清楚了，不加赘述

数据声明与访问

内存布局

全局变量与静态变量

两者都存储在 .bss 和 .data 段内，不同的是普通全局变量是外部链接，通过伪指令 .global 声明；而静态全局变量是内部链接，通过伪指令 .local 声明

如

int a = 10;
static int b = 10;

对应的汇编如下

.section .data

a: .long 10
b: .long 10

.local b
.global a

.bss 和 .data 的区别在于，.bss 中存储的是未初始化或初始化为 0 的变量，.data 则不是这样的

在声明时，一般格式为 名称: 伪指令 常见的有 .byte，.word，.long，.quad 这四个分别对应 1 字节，2 字节，4 字节，8 字节

.string 表示自动加 \0 的字符串，.ascii 表示不会自动加 \0 的字符串

.zero N 表示预留 N 字节空间，并初始化为 0，.space N 表示预留 N 字节空间，不初始化

除了 .bss 和 .data 段，还有 .rodata 段，表示 Read-only Data，一般存放字符串。一个典型的例子就是 printf("%d",number);，其中这个 %d 就会被存放到 rodata 段

C 中的一个常见的坑就是 char* str = "Hello";，不能使用 str[0] 来修改字符串，这是因为 str 指向的字符串是在 rodata 段上的

因为每次程序加载的地址都不一样，所以使用 .bss/.data/.rodata 时应使用 RIP 相对地址：变量名(%rip)

数组

全局（静态）变量数组

其声明方法与其他全局变量类似：

nums: .long 1
      .long 2
      .long 3
      .space 308

等同于

int nums[80] = {1,2,3};

访问方法也很简单

movl nums+4(%rip), %eax

等同于

int num = nums[1];

局部变量数组

相较于全部变量数组，局部变量数组更加常用，也更复杂

所谓局部变量，默认是存储在栈上的变量，其访问格式为：

$$ offset(base, index, scale) = base + index * scale + offset $$

其中 base 必须为寄存器，index 必须为通用寄存器（不能为 %rsp）或为空，scale 只能为 1,2,4,8，且 base 和 index 必须为相同大小的寄存器

正是因为在这个取址运算中用到了乘法，所以常常使用 lea 来实现高效的乘法

结构体和联合体访问与数组类似。不过结构体是不同数据类型的集合，并且需要考虑内存对齐，联合体所占字节为最大成员变量所占字节数

GDB 使用技巧

基本指令

  1. break

作用：打断点 usage

break 行号
break 函数名
break 文件名:行号
break *地址
break 对象 if 条件
rbreak 正则表达式

用 tbreak 替代 break 代表临时断点

  1. watch

作用观察变量是否被修改

usage

watch 变量名 //当变量值发生改变时暂停
rwatch 变量名 //当变量值被读取时暂停
awatch 变量名 //当变量值被读取或写入时暂停
watch 变量名 if 条件
  1. disas

反汇编命令

usage

disas //反汇编当前栈帧对应函数
disas 函数名 //反汇编此函数
disas $pc //反汇编$pc所在函数
disas 地址 //反汇编地址所在函数
disas 起始地址, 终止地址 //反汇编此地址区间
disas 起始地址, 偏移量 //从起始地址开始反汇编指定偏移量
disas /s //混合显示C源码和汇编代码
disas /b //显示汇编源码和机器指令
  1. examine

usage 标准语法：x/<N><F><U> <ADDR>

  • N 表示重复次数，连续往后查找
  • U 表示单位大小 可选 b(byte)，h(halfword)，w(word)，g(giant word)，分别对应 1 字节，2 字节，4 字节，8 字节

需要注意的是，在汇编中，w（double word）代表 4 字节

  • F 表示显示格式
x d u o t f c s a
十六进制数 有符号十进制 无符号十进制 八进制 二进制 浮点数 字符 字符串 地址

例如：x/8gx 代表 8 个 8 字节的 16 进制数（一般就是地址）
